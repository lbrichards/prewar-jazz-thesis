# Translation glossary & conventions (Japanese → English)

This is a 1992 musicology master's thesis: "Jazz Music in Prewar Japan and Its Concept"
(戦前の日本におけるジャズ音楽とその概念) by Larry B. Richards Jr. Translate into natural,
scholarly English. Preserve the author's argument and tone exactly; do not add or drop content.

## Fixed terminology
- ジャズ → jazz; ジャズ音楽 → jazz music; ジャズソング → jazz song
- 流行歌 → popular song; 大衆歌曲 → popular song / popular music
- 概念 → concept; 戦前 → prewar; 定着 → establishment / taking root
- 採譜 → transcription; （著者採譜）→ (transcribed by the author)
- 著者訳 → (author's translation); 〜頁 → p. 〜 (e.g. 351頁 → p. 351)
- 和音進行 → chord progression; 旋律 → melody; 調性 → tonality; 終止形 → cadence
- 主和音 → tonic (triad); 属和音 → dominant; 長三和音 → major triad; 短三和音 → minor triad
- ブルーノート → blue note; 即興 → improvisation; スイング → swing; シンコペーション → syncopation
- ベルカント → bel canto; 発声法 → vocal production / vocal technique
- 序論 → Introduction; 結論 → Conclusion; 文献目録 → Bibliography
- ヨナ抜き短音階 → yonanuki minor scale; 都々逸 → dodoitsu
- minstrel show → minstrel show; ティンパンアリー → Tin Pan Alley

## Personal names — romanize Japanese names SURNAME-FIRST with macrons; keep Western names as printed
- 服部良一 → Hattori Ryōichi; 中山晋平 → Nakayama Shinpei; 西條八十 → Saijō Yaso
- 堀内敬三 → Horiuchi Keizō; 南里文雄 → Nanri Fumio; 藤浦洸 → Fujiura Kō
- 二村定一 → Futamura Teiichi; 塩入亀輔 → Shioiri Kamesuke; 倉田 → Kurata; 油井 → Yui
- On first mention you may add the kanji in parentheses; not required thereafter.

## Song / work titles — use «English translation» with the Japanese on first mention, then «English» only
- 《東京行進曲》 → «Tokyo March» (東京行進曲); 《スピード時代》 → «Speed Era» (スピード時代)
- 《ダイナ》 → «Dinah»; 《別れのブルーズ》 → «Parting Blues» (別れのブルーズ)
- Keep Western titles verbatim and italic: *Rhapsody in Blue*, *Saint Louis Blues*, *Yesterdays*, etc.
- Keep existing *italic* markers for book/journal titles.

## Structural markers — COPY THESE VERBATIM, do not alter
- `[[FIGURE ...]]` lines: copy exactly, unchanged.
- `:::verse`, `:::list`, `:::` fences: keep the fence lines exactly. Inside them:
    * chord rows (e.g. `Eb,Eb,Ab,Ab,`) → copy unchanged.
    * the label `和音進行` → `Chord progression`; `歌詞` → `Lyrics`; `（歌）` → `(sung)`.
    * Japanese lyric lines → translate to English (one line per line).
    * discography entries (dates, English titles) → keep; romanize any Japanese band/track names.
- `| ... | ... |` table rows: translate the cell text, keep the pipes and the `|---|` separator.
- `> ` block quotes: translate, keep the leading `> `. Keep citations like （倉田1979:250頁） → (Kurata 1979: 250).
- Lines that are `- ` bibliography items: (only in the bib chunk) — see that chunk's instructions.
